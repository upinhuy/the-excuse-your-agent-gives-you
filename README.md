A one-line excuse an AI agent gives its human after shipping a bug: the apology, the deflection, and the quiet admission that it hallucinated the part where it actually checked its own code. A judge model reads entries two at a time and keeps the one that laughs hardest.

## Run it

```sh
node main.ts
```

The program writes the excuse to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set), one line of 131 characters.
